What this is, and what it is not

  • It is a classifier trained on 303 anonymised cardiology records collected at the Cleveland Clinic in 1988.
  • It is a way to see how four standard algorithms compare on the same data, under the same evaluation.
  • It is not trained on modern, diverse, or complete patient data.
  • It is not a screening test, a diagnosis, or a second opinion.

Every number shown anywhere in this application is read from the artefacts of an actual training run. Nothing is illustrative.

    How it works

    From a form to a number, in seven steps

    The same path runs for every request. No step is skipped, and no result is cached.

    1. 1

      Patient data

      Thirteen structured inputs, in the units the dataset records.

    2. 2

      Validation

      Types, ranges and allowed categories are checked in the browser and again on the server.

    3. 3

      Preprocessing

      The saved pipeline imputes, scales numeric inputs and one-hot encodes categories.

    4. 4

      Model

      The exported classifier scores the encoded record.

    5. 5

      Probability

      A model-estimated probability between 0 and 1 comes out.

    6. 6

      Classification

      The probability is compared against the tuned decision threshold.

    7. 7

      Explanation

      Per-feature contributions show what moved the model's own output.

    About

    Purpose, data and limits

    What this project demonstrates

    An end-to-end supervised-learning workflow on structured medical data: dataset profiling, leakage-controlled preprocessing, four algorithm families, tuned hyper-parameters, repeated cross-validation, threshold and calibration analysis, explainability, and a served inference pipeline behind a real interface.

    It was built as a university assignment and is intended for teaching and portfolio use.

    Known limitations

    • 303 records from a single hospital, collected in 1988 — small, old, and not representative of today's patients.
    • About two-thirds of the cohort is male, so performance on female patients is estimated from far fewer records.
    • The label is angiographic narrowing above 50%, not a clinical diagnosis or an outcome such as a cardiac event.
    • With 61 test records, every test metric carries a wide confidence interval; treat differences of a few points as noise.
    • Several inputs require a hospital exercise test, fluoroscopy or a thallium scan — this is not a self-assessment tool.
